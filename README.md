# About project

Built with **React Native**, featuring smooth animations, state management with **Redux Toolkit**, and clean architecture with custom hooks powered by **SWR**.

## 🚀 Features

- ⚛️ **State Management with Redux Toolkit**  
  Centralized and scalable state using Redux Toolkit with `createSlice`, `createAsyncThunk`, and `configureStore`.

- 🎞️ **Smooth Animations with Reanimated**  
  Complex UI transitions and gestures built with `react-native-reanimated` for high performance and fluid UX.

- 🔄 **Data Fetching with SWR**  
  Custom hooks using [SWR](https://swr.vercel.app/) for data fetching and caching, helping to separate **logic from UI components**.

- 🧼 **Clean Code Architecture**  
  - Separation of concerns: UI components, logic (hooks), and store layers
  - Reusable and testable components

## 🛠 Tech Stack

- **Framework**: React Native
- **Language**: TypeScript (or JavaScript)
- **State Management**: Redux Toolkit
- **Animations**: React Native Reanimated
- **Data Fetching**: SWR + Axios
- **Navigation**: React Navigation
